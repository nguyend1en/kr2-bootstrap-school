# Контрольная работа №3

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебный сайт онлайн-школы русского языка для иностранных студентов «Слово» (каталог услуг), разработанный с использованием Bootstrap. На сайте можно посмотреть курсы от уровня A1 до подготовки к ТРКИ, открыть страницу курса, записаться на пробное занятие через модальное окно и оставить заявку на обучение.

## Подключение Bootstrap

Bootstrap 5.3.8 подключён через CDN (jsDelivr):

- CSS — в `<head>` каждой страницы;
- JS Bundle — перед `</body>` (нужен для мобильного меню, выпадающего списка, модального окна и accordion).

Файл `css/custom.css` подключён после Bootstrap и содержит только минимальные правки.
