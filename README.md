# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебный сайт онлайн-школы русского языка для иностранных студентов «Слово» (каталог услуг), разработанный с использованием Bootstrap. На сайте можно посмотреть курсы от уровня A1 до подготовки к ТРКИ, открыть страницу курса, записаться на пробное занятие через модальное окно и оставить заявку на обучение.

## Подключение Bootstrap

Bootstrap 5.3.8 подключён через CDN (jsDelivr):

- CSS — в `<head>` каждой страницы;
- JS Bundle — перед `</body>` (нужен для мобильного меню, выпадающего списка, модального окна и accordion).

Файл `css/custom.css` подключён после Bootstrap и содержит только минимальные правки.

## Дополнительные функции

1. **Фильтр курсов по уровню** (`catalog.html`) — группа кнопок `btn-group` + `btn-check`: «Все курсы», «A1–A2», «B1», «B2 и выше», «Разговорный клуб». Скрипт скрывает лишние карточки утилитой `d-none` и показывает число найденных курсов.
2. **Онлайн-тест на уровень** (`test.html`) — 8 вопросов на `form-check`; после проверки показываются число правильных ответов, полоса `progress`, примерный уровень (A1–B2) и рекомендуемый курс в `alert`.
3. **Страница преподавателей** (`teachers.html`) — карточки `card` с инициалами, стажем, специализацией, языками общения (`badge`) и курсами (`list-group`).
4. **Вкладки на странице курса** (`product.html`) — компонент `nav-tabs`: «Информация о курсе», «Программа» по неделям, «Расписание групп» с количеством свободных мест.
5. **Проверка форм и уведомление** (`order.html`, модальное окно в `catalog.html`) — валидация Bootstrap (`needs-validation`, `was-validated`, `invalid-feedback`) и всплывающее уведомление `toast` после отправки.

Логика функций 1, 2 и 5 находится в `js/main.js`.
