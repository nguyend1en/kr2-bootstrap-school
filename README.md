# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебный сайт онлайн-школы русского языка для иностранных студентов «Слово» (каталог услуг), разработанный с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных курсов;
- полноширинный блок записи на тест на `container-fluid`;
- подвал страницы.

## Используемые технологии

- Bootstrap 5.3;
- CSS;
- Git;
- GitHub.
